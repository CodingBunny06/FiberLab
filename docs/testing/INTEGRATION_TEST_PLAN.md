# FiberLab v1.0 Integration Test Plan

## 1. Purpose

Verify that the application, physics, visualization, and Guardian workflows operate together through their agreed interfaces. This is a test plan, not evidence that tests have already been executed.

## 3. Automated checks

Run from the repository root:

```bash
ruff check .
ruff format --check .
python -m pytest -v
```

Record exact output, test count, skipped tests, and commit SHA. Report a check as passing only if it completed successfully on the commit under review.

## 4. Physics unit tests

Verify valid refractive-index inputs; `n_core > n_cladding > 0`; numerical-aperture and critical-angle results; radians convention; attenuation and output-power calculations; positive power and fiber-length requirements; non-negative attenuation; invalid and non-finite values.

## 5. Visualization tests

Verify Plotly Figure return types; expected traces and data; axis titles and units; legends and titles; compatible array lengths; predictable handling of empty and invalid data.

## 6. Application workflows

### Fiber Explorer
- [ ] Page renders.
- [ ] Valid inputs produce numerical results.
- [ ] Invalid inputs produce understandable feedback.
- [ ] Ray visualization receives the agreed ray-data structure.

### Attenuation Laboratory
- [ ] Page renders.
- [ ] Input power, attenuation, and length are validated.
- [ ] Output power and total loss are displayed.
- [ ] Graph data matches calculated values.

### Signal Propagation
- [ ] Page renders.
- [ ] Input waveform and fiber parameters are validated.
- [ ] Output waveform is generated by the physics layer.
- [ ] Comparison visualization receives compatible arrays.

### Learning Lab
- [ ] Page renders.
- [ ] Learning content is accessible.
- [ ] Navigation works.

## 7. Guardian workflows

- [ ] Local project inspection completes.
- [ ] Diagnostics show file and recommendation details.
- [ ] Integration workspace creation is tested.
- [ ] Candidate selection and integration are tested.
- [ ] Timeout and failure reporting are tested.
- [ ] GitHub PR inspection remains read-only unless explicit comment publishing is selected.
- [ ] Untrusted candidate code is not executed during static PR inspection.

## 8. Manual regression

- [ ] Launch application using documented command.
- [ ] Navigate through every page.
- [ ] Exercise valid, invalid, boundary, and empty inputs.
- [ ] Confirm displayed units and labels.
- [ ] Confirm normal workflows do not crash.
- [ ] Confirm Guardian actions match their confirmation text.
