# FiberLab 🔬

### Interactive Optical Fiber Communication Simulator

FiberLab is an educational and engineering simulation platform designed to explore optical fiber physics and communication systems through interactive experiments, scientific calculations and visualizations.

## Objectives

- Explore optical fiber properties.
- Understand total internal reflection.
- Calculate numerical aperture and acceptance angle.
- Simulate optical signal attenuation.
- Visualize signal propagation and dispersion.
- Understand optical communication systems.

## Technology Stack

- Python
- NumPy
- SciPy
- Streamlit
- Plotly
- Matplotlib
- Pytest
